# Bitcoin Core test vectors

## script_tests.json, tx_valid.json, tx_invalid.json, sighash.json

Copied unmodified from `src/test/data/` of Bitcoin Core, commit
3f9c55426a12a16bd11de6dec139c4df58788360.

## script_assets_test_subset.json

A subset (to limit file size) of `unit_test_data/script_assets_test.json` from
https://github.com/bitcoin-core/qa-assets (generated by Core's `feature_taproot.py`),
downloaded on 2026-10-21 from
https://github.com/bitcoin-core/qa-assets/raw/main/unit_test_data/script_assets_test.json

The full file can be run by pointing the environment variable
`ELECTRUM_SCRIPT_ASSETS_TEST_JSON` to it.

The subset was produced with:

```python
import json
import sys

MAX_ENTRY_SIZE = 50_000
src, dst = sys.argv[1], sys.argv[2]
with open(src) as f:
    tests = json.load(f)
best = {}
for i, t in enumerate(tests):
    key = (len(json.dumps(t, separators=(',', ':'))), i)
    if t["comment"] not in best or key < best[t["comment"]][0]:
        best[t["comment"]] = (key, t)
subset = [t for key, t in sorted(best.values(), key=lambda x: x[0][1]) if key[0] <= MAX_ENTRY_SIZE]
with open(dst, "w") as f:
    f.write("[\n" + ",\n".join(json.dumps(t, separators=(',', ':')) for t in subset) + "\n]\n")
```
